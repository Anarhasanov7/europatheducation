Как получить токены

Пошаговая инструкция

Facebook + Instagram

  1. Откройте Graph API Explorer
  2. Выберите приложение EuroPath Education
  3. Нажмите Get Token → Get User Access Token
  4. Выберите права: pages_manage_posts, pages_read_engagement, instagram_content_publish
  5. Нажмите Get Access Token и авторизуйтесь
  6. Снова нажмите Get Token → Get Page Access Token
  7. Выберите страницу EuroPath Education и скопируйте токен в поле выше
  8. Для Instagram: в Graph API Explorer выполните /{page-id}?fields=instagram_business_account
  9. Скопируйте значение id из ответа в поле Instagram Business ID

Threads

  1. Откройте Threads API в вашем Meta приложении
  2. Настройте Threads API и получите User ID и Access Token
  3. Вставьте их в соответствующие поля выше
